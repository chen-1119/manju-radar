# 漫剧雷达

Windows 本机工具：按任意关键词搜索百度网盘与夸克网盘的公开分享，包括作品剧集、课程教程、电子书、软件资料；查看近期热门 AI 漫剧，并在各自账号授权后转存直达分享。

## 在其他电脑使用

从 GitHub Releases 下载 `manju-radar-Windows.zip`，完整解压后双击 `漫剧雷达.exe`。主程序和夸克组件已包含在压缩包里，无需安装 Node.js 或 Python。关闭程序窗口会停止本机搜索服务；再次双击即可启动。浏览器若未自动打开，可手动访问 <http://127.0.0.1:4177/>。

百度转存：点击“打开百度登录窗口”，工具会使用这台电脑已有的 Edge 或 Chrome 打开专用窗口。请自己在百度官方页面扫码或登录，完成后回到工具使用“一键转存”。登录状态保存在工具专用的本地浏览器目录，每台电脑需要独立登录。

夸克转存：点击页面中的“扫码登录夸克网盘”，用夸克 App 扫码确认。两个平台均默认保存到自己的网盘根目录 `/`，点击转存会保存该分享的全部文件。百度返回完成文件清单时，页面显示实际保存路径；只返回任务号时，页面保留任务号并提示稍后核对，避免重复提交。同名文件使用百度的重命名保存策略，避免覆盖已有文件。

v0.2.0 改用百度网页登录态支持根目录保存，与旧版的官方 OAuth 授权独立，需要重新登录。百度与夸克实际账号的根目录保存仍需用户完成登录后验证；百度要求验证码时，需要用户自行完成，程序不会自动处理验证码。

## 搜索说明

每次点击搜索会按输入的关键词同时查询[盘搜索公开 API](https://pansousuo.com/api-docs)与 [PanSou 聚合服务](https://github.com/fish2018/pansou)，合并百度、夸克分享。PanSou 使用公共实例 `https://so.252035.xyz`，搜索来源包括公开频道和资源站插件，卡片底部显示来源；公共实例可用性与收录范围可能变化。默认“不限内容”，不会自动加入 AI 漫剧关键词，也不会排除教程素材；可以输入作品名、课程名或“Python 基础”等多个关键词，匹配规则取决于来源。还可选择漫剧作品、教程素材和时间范围。

首次搜索包含索引第一页与聚合结果。点击“加载更多索引结果”继续读取后续页；重复分享按官方网盘链接合并，尽量保留提取码与各来源标识。百度、必应、Google 的补充入口在对应引擎打开带关键词的网页搜索，不将这些网页结果自动导入工具。

首页热门内容仍按 AI 漫剧公开索引热度和近 31 天收录时间筛选；收录时间不等于作品首播时间。公开索引可能延迟，分享链接仍需用户核对有效性与使用授权。

若希望扩大搜索范围，可在页面底部设置七牛云百度搜索或 [Brave Search API](https://brave.com/search/api/)。已配置的 API 会与公开索引和 PanSou 同时查询，合并结果并按分享链接去重；某个来源失败时仍显示其他来源结果。每个已配置 API 的首次双平台搜索会发出 2 次请求，测试连接发出 1 次；加载后续索引页不会重复调用。网页搜索会使用该账号的 API 额度。密钥只保存在这台电脑的 `%LOCALAPPDATA%\ManjuRadar\config.local.json`，不会打进发行包。页面支持独立保存、测试、清除两个服务的本机密钥，兼容旧版 Brave 设置。

### 七牛云搜索

1. 可通过[作者的七牛云邀请链接](https://s.qiniu.com/RbuYve)注册，活动奖励与资格以七牛官方规则为准。该链接是注册入口，不是查询接口。
2. 按[官方密钥教程](https://developer.qiniu.com/aitokenapi/12884/how-to-get-api-key)在七牛控制台创建自己的 **AI API Key**，在工具底部“七牛云 · 百度搜索”中保存。无需提供七牛账号的 AK/SK。
3. 点击“测试连接（1 次请求）”核对接口权限与余额，然后正常搜索关键词。每条网页结果会显示“七牛云百度搜索”来源，能识别到的网盘链接和提取码可用于转存。

实际使用官方[全网搜索接口](https://developer.qiniu.com/aitokenapi/13192/web-search-api) `POST https://api.qnaigc.com/v1/search/web`，认证为 `Authorization: Bearer <AI API Key>`。无代理网关，也不额外调用大模型生成答案。七牛接口没有一天的时间选项，因此一天筛选先查询一周，再根据结果日期筛选；时间筛选时未知日期结果被排除。

邀请奖励为模型 Token，搜索费用是否可使用奖励抵扣需在控制台核对资源包范围，工具不承诺免费搜索次数。未使用真实用户密钥验证调用或抵扣结果；余额、权限不足会显示提示并保留其他来源结果。开发时也可通过 `QINIU_AI_API_KEY`、`BRAVE_SEARCH_API_KEY` 环境变量设置，各自优先于本机配置，清除页面密钥不改变环境变量。

## 账号与数据

- 百度使用工具专用的 Edge/Chrome 登录资料，保存在 `%LOCALAPPDATA%\ManjuRadar\baidu-browser`。转存流程参考 [bdcli](https://github.com/Youwillrememberme/bdcli) 的网页接口实现，依赖百度非公开接口，平台更新后可能失效。工具不读取日常使用的浏览器资料，不把 Cookie 返回到页面或写入日志。
- 夸克使用 [QuarkPan](https://github.com/lich0821/QuarkPan) 1.0.5。它依赖夸克非公开接口，平台更新后可能失效。登录 Cookie 由该组件以**明文 JSON**保存在 `%LOCALAPPDATA%\ManjuRadar\quark`。只在可信的私人电脑扫码登录。
- 百度、夸克账号各自独立授权；这些本机目录、搜索密钥及登录资料均不应上传到 GitHub。

## 从源码运行与构建

开发时需 Node.js 20 以上；运行 `npm install`、`npm test`、`npm start`。若不使用发行包，夸克组件可用 `安装夸克转存组件.cmd` 安装，它需要本机 Python 3。百度使用现有 Edge 或 Chrome，无需旧版的 bdpan 安装脚本。

Windows 发行包通过 Node 单文件程序和 PyInstaller 构建。先用 Python 3.12 的独立虚拟环境安装 `quarkpan==1.0.5`、`qrcode[pil]` 和 `pyinstaller`，构建 `quarkpan.exe`、`quark-login.exe` 放入 `build/quark-components`；再运行 `npm run build:win`，输出位于 `dist/漫剧雷达-Windows`。构建输出、虚拟环境、本机配置均被 `.gitignore` 排除。
