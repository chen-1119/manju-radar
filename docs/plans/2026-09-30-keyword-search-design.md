# 任意关键词搜索

用户希望百度与夸克资源搜索不限于 AI 漫剧，输入关键词即可检索。

采用默认“不限内容”的方案：索引查询直接使用输入关键词，网页查询仅添加对应网盘名称，不自动加入 AI 漫剧；保留漫剧作品、教程素材作为可选范围。相比只改提示文字，这也修复网页查询隐含的内容限制。新增多个第三方索引需要评估接口和维护成本，本次使用现有索引与可选网页搜索。

已配置网页搜索时，同时查询索引和网页，合并、去重。保留可用来源结果，分别返回部分失败提示与全部失败错误。搜索代码独立为模块，便于验证查询、结果合并及异常处理。登录资料、转存流程及漫剧热点沿用当前实现。

用户后续要求更多搜索引擎与来源，并明确选择保存到网盘根目录。新增 PanSou 公共聚合源，复用其频道和插件来源，默认无需密钥；百度、必应、Google 提供显式网页搜索入口；盘搜索按页加载更多。重复分享保留提取码和来源标识，某源失败时保留其他结果。

夸克指定根目录 `/`。百度原官方 OAuth 工具无法写入根目录，改为工具专用 Edge/Chrome 浏览器资料，由用户在官方页面完成登录，然后使用网页转存接口。浏览器资料独立于用户日常浏览器，Cookie 不暴露给前端或日志。识别排队任务与真实完成清单，重名使用 newcopy。转存过程不处理验证码。新增 Playwright Core 作为本机浏览器控制依赖，打包时随应用分发。

验证：任意关键词不带 AI 漫剧附加词；非漫剧教程、电子书不会被默认筛除；索引有结果时网页仍参与；重复链接去重；一个来源失败时另一个结果保留；无网页密钥时使用索引与聚合；后续页不会重复聚合或消耗网页额度。百度根目录请求、提取码验证、分页文件列表和完成状态通过模拟接口验证。运行原有转存与热点测试，验证 Windows 打包程序搜索与本机浏览器运行时。实际账号保存需要用户登录后验证。
